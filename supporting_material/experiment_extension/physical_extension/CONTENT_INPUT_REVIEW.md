# Capture provenance and the held-out content study

The retained trace links 5,141,673 frozen feature rows to 31 source CSV files. The trace, including the original and labelled source digests, is available in [SOURCE_ROW_TRACE.json](../SOURCE_ROW_TRACE.json). Its unit of identity is a feature file and row.

The local shared dataset directory also contains eight PCAP files assigned names for earlier train, validation, test or known partitions. The inventory contains no capture registry or merge/split offsets. A separate provider CSV export has 309 files and a README documenting combined and shuffled rows. The retained provider README SHA-256 is `76d79460e416b88a28e9db3573255ea5fb5fca836fc2e3d3f794a4df2b9e7e98`. A bounded search of the ToN administrative and archived research directories found no parent-capture register for the 31 source digests.

The dataset publisher documents merging captures with Mergecap, splitting with TCPDump and extracting features with DPKT. The description does not identify which acquisition and boundaries produced each retained feature segment. The number of independent acquisitions represented in the frozen corpus remains unknown. [UNB dataset description](https://www.unb.ca/cic/datasets/iotdataset-2023.html)

IoT-23 was considered as a separate source. Its publisher documents per-scenario captures and flow-level Zeek labels. These are different observations from the frozen CICIoT2023 feature windows. The per-scenario server timed out during the local access check. The separate 21,510,801,277-byte Zenodo release has a published checksum, but its catalog supplies no mapping from its flow labels to the present 39-feature observations. No such substitution or cross-corpus result enters the paper. [Scenario and label documentation](https://www.stratosphereips.org/datasets-iot23) · [Published archive](https://doi.org/10.5281/zenodo.4743746)

**Current experimental status.** Parent mapping for a qualified split is missing. There is no independently qualified training, validation or test cohort, new model fit, three-representation test score, or measured timely-correct transport score in this study. The retained 896-row interface diagnostic and historical hardware timing results keep their original denominators. Required inputs are acquisition identifiers and boundaries traceable to the frozen source segments, or a separately documented cohort with sufficient independent groups, compatible feature observations and matched ground truth.
