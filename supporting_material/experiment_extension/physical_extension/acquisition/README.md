# Acquisition source

The pilot launcher, normalizer, enrollment reader and dispatch wrapper in this directory are byte copies of the amended acquisition sources. The phase builder derives campaign-scoped copies for the subsequent acquisitions and binds the derived hashes in each input freeze. The engineering check uses its own two-condition registration to measure both initial backlog states before a scientific calibration can qualify.

The base hardware planner, bundle builder, schema and block-summary implementation are in [hardware](../../hardware/). The instrumented private RC1 trees, deployment receipts, enrollment data, host keys and raw streams stay with the controlled archive. A lab with that archive runs the wrapper from the actual campaign root, with the exact frozen private layout recorded in its manifest. The public result verification uses only the exported role-labelled trajectories and counts.
