# Supporting material

These files support independent review and reproducibility. They are not
needed to read the submission PDFs.

- `formal_campaign_audit/` — path-free campaign identity, accepted-attempt
  index, validators, configuration snapshot, and integrity manifest.
- `methodology_repair/` — historical V1.3 outputs and exact archived source,
  plus corrected active source; start with `CORRECTIONS.md` for version and
  upload-endpoint semantics.
- `methodology_validation/` — public selector reconstruction, duplicate-label
  audit, independent ledger reconstruction and frozen-input identity checks.
- `contention_validation/` — executed deterministic shared-service/stage-delay
  counterexamples with event/service records, plus a retained historical
  unexecuted detection-value protocol.
- [`experiment_extension/`](experiment_extension/) — completed
  [replacement-cohort physical comparisons](experiment_extension/physical_extension/README.md)
  and the separate [CICIoMT2024 content/transport study](experiment_extension/content_measurement/README.md),
  alongside input discovery/freezing, scoring, planning and the retained Codex
  handoff. Preparation fixtures remain distinct from research measurements.
- `crfa_hardware/` — path-free CRFA hardware-extension summaries, event/service
  ledgers, timing reconstruction, protocol, failure provenance, and hashes.
- `evidence_snapshot/` — machine-readable evidence and number provenance used
  to validate the displayed results.
- `archive/` — historical material retained for traceability and not used by
  the clean submission package.

The private historical physical-campaign archive and raw ledgers, source packet
captures, private historical models, host identities and network addresses are
not stored here. The separate content study includes its declared public
models, predictions and measured transport exports. See the
root [`REPRODUCIBILITY.md`](../REPRODUCIBILITY.md) for the access and
reproduction boundary.
