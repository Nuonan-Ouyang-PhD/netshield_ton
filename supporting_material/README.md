# Supporting material

These files support independent review and reproducibility. They are not
needed to read the submission PDFs.

- `formal_campaign_audit/` — path-free campaign identity, accepted-attempt
  index, validators, configuration snapshot, and integrity manifest.
- `methodology_repair/` — executable offline replay/simulation, fixed seeds,
  result tables, run metadata, and hashes.
- `evidence_snapshot/` — machine-readable evidence and number provenance used
  to validate the displayed results.
- `archive/` — historical material retained for traceability and not used by
  the clean submission package.

The raw physical-campaign archive, raw event ledgers, packet captures, private
models, host identities, and network addresses are not stored here. See the
root [`REPRODUCIBILITY.md`](../REPRODUCIBILITY.md) for the access and
reproduction boundary.
